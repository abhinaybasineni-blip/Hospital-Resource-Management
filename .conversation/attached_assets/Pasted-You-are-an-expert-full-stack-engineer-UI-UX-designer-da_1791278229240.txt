Create a dashboard for hospitals to monitor:

2. Oxygen equipment

6. SUPABASE SECURITY
==================================================

Enable Row Level Security for every user-owned table.

Every user-owned table must contain user_id.

Users must only be able to access their own hospital/resource records.

Never trust user_id coming from the frontend.

Get the authenticated user identity from the JWT on the backend.

Implement proper RLS policies.

Test that:

User A cannot access User B's records.

Users cannot update another user's resources.

Users cannot delete another user's records.

Users cannot access another hospital's private data.

Never expose Supabase secret/service keys in frontend code.
